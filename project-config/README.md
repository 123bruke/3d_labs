# Project configuration

This folder contains the human-readable project metadata and build configuration used by the application.

- `metadata.json` describes the application.
- `index.html` defines the document shell and page metadata.
- `tsconfig.json` contains TypeScript compiler settings.
- `vite.config.ts` contains the Vite development and build settings.

The lockfiles remain at the repository root because package managers expect them there when installing dependencies.
